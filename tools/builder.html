🌐 Step 1: Deploy to Edge Hosting (Cloudflare / Netlify / Vercel)
Host your hardened single-file recovery terminal at https://sos.yourdomain.com

Option A: Direct Upload via Web Dashboard (Zero Git Secrets)

  1. Log into the Cloudflare Dashboard.
  2. Navigate to Workers & Pages → Select your Pages project (or click Create application → Pages → Direct Upload).
  3. Create an empty folder, place the downloaded index.html (and _headers) inside, and drag it into the dropzone.
  4. Click Deploy site. Your vault is live worldwide on Cloudflare's Anycast Edge!

Option B: CLI Direct Deploy

./scripts/deploy.sh payload.json --provider cloudflare --project identity-recovery

Option A: Netlify Drop Web Dashboard (Zero Git Secrets)

  1. Log into the Netlify Dashboard.
  2. Navigate to Sites and scroll down to the Deploy manually / Netlify Drop section.
  3. Drag-and-drop the folder containing your downloaded index.html (and netlify.toml).
  4. Your recovery vault is live with full edge security header parity!

Option B: CLI Direct Deploy

./scripts/deploy.sh payload.json --provider netlify --site <YOUR_NETLIFY_SITE_ID>

Option A: CLI Direct Deploy (Zero Git Secrets)

Deploy directly to Vercel production edge without committing ciphertext:

./scripts/deploy.sh payload.json --provider vercel --project identity-recovery

Option B: Git Integration

  1. Import your repository in the Vercel Dashboard.
  2. Configure Root Directory: . and Output Directory: public.
  3. Deployments automatically apply strict security headers from vercel.json.

For private repositories or standard Git workflows across any provider, commit and push:

mv ~/Downloads/index.html public/index.html git add public/index.html git commit -m "vault: rotate encrypted recovery payload" git push origin main
